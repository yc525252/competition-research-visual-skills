# Word文档编辑

使用当前可用工具创建或修改Word文档，并验证内容与版式。

## 必要输入

- 文档或内容
- 修改范围
- 模板与审阅需求

## 工作方式

1. 读取原文并确认标题、表格、页眉页脚和需要保留的内容。
2. 选择当前实际可用的文档工具；需要修订或批注时确认工具是否支持。
3. 按约定范围编辑，检查表格、编号与分页，并交付实际文件。

## 交付

- DOCX文件
- 修改说明
- 必要的渲染检查

## 工具条件

可读写DOCX的实际工具；本仓库不提供该引擎。

## 边界

- 本入口不包含任何厂商文档引擎或受限模板。
- 不把普通覆盖保存描述为已生成修订记录。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-docx 按这份学校模板编辑报告，只改方法章节，保留其他内容并交付可编辑DOCX。
```
