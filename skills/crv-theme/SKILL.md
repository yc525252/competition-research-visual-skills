# 文档与视觉主题

为文档、演示或网页建立适配内容的主题规则并验证代表页面。

## 必要输入

- 内容和媒介
- 受众与风格偏好
- 品牌与可访问性约束

## 工作方式

1. 根据媒介、内容密度和读者确定主题目标。
2. 定义语义颜色与字体层级，将其映射到标题、正文、数据和强调元素。
3. 在内容最密集与最稀疏的页面检查对比、节奏和一致性。

## 交付

- 配色与字体规则
- 组件映射
- 代表页面检查

## 工具条件

文本或相应媒介的编辑工具。

## 边界

- 不捆绑原项目的预设主题、字体或资产。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-theme 为这份科研报告定义克制的主题，说明标题、正文、数据和提示信息的颜色与字体规则。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
