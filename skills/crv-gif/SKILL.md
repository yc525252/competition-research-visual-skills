# 动画GIF

制作适合指定渠道的循环动画并检查尺寸、帧率和文件体积。

## 必要输入

- 动画内容
- 尺寸、时长与渠道限制
- 素材

## 工作方式

1. 确认循环动作和关键帧，按目标渠道确定尺寸、时长与体积。
2. 用实际动画或图像工具生成各帧并编码。
3. 检查循环衔接、文字可读性、体积与输出尺寸。

## 交付

- GIF文件
- 预览
- 尺寸帧率等参数

## 工具条件

实际逐帧绘图或动画编码工具。

## 边界

- 不预设渠道限制永久不变；用本次要求或当前资料确认。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-gif 制作一个3秒循环的进度提示GIF，按我提供的尺寸和体积限制导出。
```
