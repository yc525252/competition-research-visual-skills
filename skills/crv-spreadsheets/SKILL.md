# 表格与数据分析

使用表格工具编辑工作簿、检查公式和单位，并形成可追溯结果。

## 必要输入

- 工作簿或数据
- 字段与单位
- 编辑或分析要求

## 工作方式

1. 区分原始数据、计算区与展示区，保留字段定义和来源。
2. 在可用表格工具中编辑，优先用可审阅公式表达计算。
3. 检查公式引用、空值、日期、单位、汇总与重算结果。

## 交付

- 工作簿或表格
- 公式与假设说明
- 结果核对

## 工具条件

Excel兼容编辑工具或可靠的工作簿库；本仓库不提供重算引擎。

## 边界

- 没有计算引擎时说明公式尚未重算。
- 不随意将公式替换成硬编码值。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-spreadsheets 整理这份成本表，保留原始数据，用公式计算汇总，并标注所有假设和单位。
```
