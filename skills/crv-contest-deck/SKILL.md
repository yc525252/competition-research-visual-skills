# 创赛PPT内容设计

把创业项目转成网评、路演或答辩PPT的页序、结论和证据安排。

## 必要输入

- BP与证据
- 展示场景和受众
- 页数、时长与评分要求

## 工作方式

1. 区分自行阅读的网评稿和配合讲解的路演稿，依据时长调整信息密度。
2. 为每页写出一个待证明的结论，并指定支持它的资料或图表。
3. 安排问题、解决方案、验证、实施与团队等内容的承接，删除没有作用的重复页。
4. 用户需要实际PPTX时选择原生或图片路线，完成后检查渲染和数据一致性。

## 交付

- 逐页内容稿
- 讲稿安排
- 证据与页面对应

## 工具条件

需要PPTX时必须具备实际演示制作与渲染工具。

## 边界

- 逐页文案不是已经生成的演示文件。
- 匿名和附件要求按本次赛事通知处理。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-contest-deck 将这份BP规划成6分钟路演，输出逐页结论、证据位置和对应口头讲稿。
```
