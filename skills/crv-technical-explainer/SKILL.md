# 技术讲解与答辩

把复杂技术改写成受众能跟上的条件、模型、推理与结论。

## 必要输入

- 真实原理与结果
- 受众背景
- 时长和关键边界

## 工作方式

1. 确认听众已有知识和必须理解的核心问题。
2. 从必要条件开始，逐步说明机制或推理，使用类比时标明它与真实机制的差别。
3. 给出短版和展开版，检查简化是否改变了结论适用条件。

## 交付

- 讲解骨架
- 短答与展开回答
- 追问清单

## 工具条件

文本或示意图工具；具体事实须有原资料支撑。

## 边界

- 类比帮助理解，不能作为科学证明。
- 使用通用解释方法，不冒充现实人物。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-technical-explainer 把这个控制方法讲给非本专业评委听，分别写30秒短答和保留关键条件的展开回答。
```
