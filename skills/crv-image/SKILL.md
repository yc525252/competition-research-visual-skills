# 图像生成与编辑

规划并使用当前图像工具完成位图生成或编辑，核对结果是否符合用途。

## 必要输入

- 场景与风格
- 尺寸和用途
- 编辑时的原图

## 工作方式

1. 确认需要位图、矢量还是现有界面编辑，按交付类型选择工具。
2. 描述主体、构图、尺寸、背景和保留条件，再调用真实可用的图像工具。
3. 检查结果中的文字、标志和关键内容，按需要迭代。

## 交付

- 实际生成图
- 必要的变体
- 结果说明

## 工具条件

独立安装或当前Agent提供的图像工具，可能需要服务权限。

## 边界

- 没有图像生成能力时只能交付说明或提示词，不能声称生成了图片。
- 不捆绑模型、服务凭据或厂商实现。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-image 为这个技术项目生成一张16:9概念配图，保留用户给出的设备结构，背景简洁。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
