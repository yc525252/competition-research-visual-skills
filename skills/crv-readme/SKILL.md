# 开源README

为公开仓库写清项目用途、快速开始、能力范围和维护方式。

## 必要输入

- 项目内容
- 目标读者
- 真实安装与运行方式

## 工作方式

1. 让首屏说明解决的问题、适用对象和最短尝试路径。
2. 从实际实现整理依赖、安装、用法、输出和限制。
3. 检查命令与链接，并根据真实贡献和许可证添加说明。

## 交付

- README
- 可复制示例
- 文档链接

## 工具条件

仓库文件读取与实际命令验证能力。

## 边界

- 不添加虚构徽章、测试通过或兼容性声明。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-readme 为这个仓库编写中文README，让新读者能理解用途并按真实命令跑通最小示例。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
