# 图片版演示路线

规划视觉优先的图片版演示，并明确图片与可编辑内容的区别。

## 必要输入

- 内容资料
- 使用场景与风格
- 页面数量及文件要求

## 工作方式

1. 先提炼内容、锁定每页要表达的结论和已有证据。
2. 确定统一风格与页面视觉说明，用真实素材或实际图像工具制作。
3. 检查生成图中的文字、数字和事实，组装后说明哪些内容不可直接编辑。

## 交付

- 逐页视觉说明
- 页面图片
- 具备工具时的组装文件

## 工具条件

图像生成或设计工具；演示组装与编辑另需工具。

## 边界

- 不包含SlideMuse原项目、模型接口或图片还原引擎。
- 整页图片不等于原生可编辑PPT；还原能力依赖外部工具。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-image-deck 把这份报告做成视觉优先的图片演示，先给每页内容与视觉计划，并标明可编辑范围。
```
