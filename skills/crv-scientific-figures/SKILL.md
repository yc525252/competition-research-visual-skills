# 科研静态图

将真实数据制作成可复查的静态科研图，交付绘图代码和图件。

## 必要输入

- 原始数据与字段
- 单位、样本与误差定义
- 版面和文件要求

## 工作方式

1. 确认比较目标、变量、单位、统计量和误差的真实含义。
2. 选择图型与面板结构，使主结论和辅助证据的主次明确。
3. 用实际绘图库生成图件，保留数据处理代码和来源。
4. 检查标注、图例、坐标、裁切及矢量导出效果。

## 交付

- 绘图代码
- SVG或PDF
- 预览与数据处理说明

## 工具条件

Python绘图库如matplotlib，及用户需要格式的导出环境。

## 边界

- 不伪造误差条、样本量或显著性。
- 动态仪表盘应另选交互工具。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-scientific-figures 用这组重复实验数据绘制对比图，说明误差定义，并输出代码、SVG和PNG。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
