# 静态视觉与海报

为明确传播目标设计海报或静态视觉，交付实际图件。

## 必要输入

- 受众与传播目标
- 文案和素材
- 尺寸、渠道与品牌要求

## 工作方式

1. 确定读者最先看到的核心信息与阅读顺序。
2. 按尺寸安排网格、字体、图像与留白，使用有权使用的素材。
3. 检查文字、清晰度、裁切和导出规格。

## 交付

- 版面方案
- PNG或PDF等图件
- 素材说明

## 工具条件

实际设计、绘图或排版工具。

## 边界

- 不捆绑受限字体或第三方海报资源。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-poster 根据这段活动文案设计A4海报，突出日期与报名方式，交付PDF和预览图。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
