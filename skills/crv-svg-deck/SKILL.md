# SVG演示制作路线

按统一设计约束制作SVG页面，并在具备导出工具时转为PPTX。

## 必要输入

- 内容与版式要求
- 素材与字体
- SVG或PPTX交付要求

## 工作方式

1. 建立画幅、字体、颜色与页面信息层级的统一约束。
2. 根据实际内容逐页制作SVG，保持图表数值和文字可读性。
3. 检查视框、溢出与字体，只有导出工具存在时才承诺PPTX交付。

## 交付

- SVG页面
- 设计约束
- 可用时的PPTX导出

## 工具条件

SVG制作和渲染工具；PPTX导出另需合适实现。

## 边界

- 不包含ppt-master原项目、模板、图标或导出脚本。
- SVG文本与对象在导出后是否可编辑需实际验证。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-svg-deck 用统一画幅制作这5页SVG技术说明，保留图表数据，并说明PPTX导出所需工具。
```
