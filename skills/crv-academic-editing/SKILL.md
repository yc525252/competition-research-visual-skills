# 学术英文编辑

编辑已有学术内容的段落逻辑、章节职责和英文表达，保留证据与结论边界。

## 必要输入

- 待改文本与上下文
- 术语和证据
- 期刊要求及允许修改范围

## 工作方式

1. 先明确段落的任务与核心主张，再检查支持它的证据是否在场。
2. 修复跳跃和章节混用，保持观察结果与解释、推测的差别。
3. 统一术语和谨慎程度，改善英文清晰度，并解释重要结构修改。

## 交付

- 编辑稿
- 主要修改原因
- 未解决的科学问题

## 工具条件

文本编辑能力与用户提供的领域术语。

## 边界

- 不通过语言美化制造机制、因果关系或新颖性。
- 明确期刊格式优先于通用风格偏好，不保证录用。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-academic-editing 先检查这段Discussion的论证，再润色为清晰克制的英文，附重要修改说明。
```
