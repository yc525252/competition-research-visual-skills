# PPT单页逻辑

优化已有幻灯片的结论标题、信息主次和证据表达。

## 必要输入

- 页面文字或截图
- 页面要证明的观点
- 受众与真实数据

## 工作方式

1. 先说明该页应让读者记住的一条结论。
2. 检查图、数据、正文是否共同支持它；将旁支移到其他页或备份页。
3. 改写标题并调整阅读顺序，保留关键条件、单位和来源。

## 交付

- 结论标题
- 删改清单
- 信息层级建议

## 工具条件

图片或PPT读取能力；实际修改文件需要对应编辑工具。

## 边界

- 不为了标题冲击力扩大样本、测试或预测的适用范围。
- 这是通用审稿视角，不代表任何现实讲师意见。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-slide-logic 检查这三页是否一页一事，分别给出结论标题、保留内容和需要移动的证据。
```
