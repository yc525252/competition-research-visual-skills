# 用户品牌规范

将用户提供的品牌颜色、字体、标志与使用条件应用到指定材料。

## 必要输入

- 有权使用的品牌规范
- 目标材料
- 输出约束

## 工作方式

1. 读取用户指定规范，确认标志、字体、颜色和使用限制。
2. 映射到标题、正文、图表与背景，兼顾对比度和可读性。
3. 检查一致性并记录无法取得或替代使用的素材。

## 交付

- 品牌应用规则
- 材料修改
- 一致性检查

## 工具条件

目标材料的实际编辑工具。

## 边界

- 不默认使用某家公司的官方品牌，也不暗示品牌方背书。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-brand 把用户提供的品牌手册应用到这份PPT，统一颜色与字体并保留标志使用要求。
```
