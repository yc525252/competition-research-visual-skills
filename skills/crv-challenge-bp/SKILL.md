# 小挑创业计划书

撰写或审查挑战杯创业计划类BP，对齐实际模板、项目阶段和评分证据。

## 必要输入

- 赛事通知与模板
- 是否注册与实际项目阶段
- 用户、技术、验证、团队材料

## 工作方式

1. 以用户提供的赛事模板为目录依据，确认申报主体和项目成熟度。
2. 沿需求、方案、验证、客户价值、商业路径组织论证，每项关键主张对应证据。
3. 财务部分区分历史事实和预测，说明数量、单价、成本与时间范围等假设。
4. 审查跨章节数字和能力表述，最后按篇幅要求收敛正文。

## 交付

- 章节正文
- 证据对应表
- 待补信息

## 工具条件

文本与表格读取工具；需要Word时使用可用的文档编辑工具。

## 边界

- 学术作品申报应按该作品的实际要求处理。
- 不提供固定官方评分权重或保证获奖的表述。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-challenge-bp 根据比赛模板和现有证据重写商业模式章节，列出每个结论的依据和预测假设。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
