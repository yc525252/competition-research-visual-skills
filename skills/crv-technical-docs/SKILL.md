# 技术与接口文档

基于实际代码、接口与运行方式编写可操作的技术文档。

## 必要输入

- 代码或接口
- 读者
- 实际运行与配置方式

## 工作方式

1. 从实际代码和配置确认功能、接口与依赖。
2. 写清输入、输出、前置条件和错误处理，再给可复现示例。
3. 检查命令、字段和路径，明确哪些能力已经验证。

## 交付

- 使用或开发文档
- 接口说明
- 可验证示例

## 工具条件

代码读取与适合项目的验证工具。

## 边界

- 不猜测不存在的CLI参数或API响应。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-technical-docs 根据这个API实现编写接口文档，列出请求、响应、错误和可复现示例。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
