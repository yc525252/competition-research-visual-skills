# 演示主题与版式

定义可复用的演示配色、字体、画幅、网格与页面版式规则。

## 必要输入

- 内容类型与场景
- 品牌或模板
- 画幅与输出约束

## 工作方式

1. 读取用户品牌和模板，确认画幅与使用场景。
2. 定义标题、正文、图表与注释层级，建立可重复使用的版式规则。
3. 用代表页面验证长标题、数据密度和颜色对比；新增风格登记适用场景。

## 交付

- 主题规则
- 版式规范
- 页面样例要求

## 工具条件

文本或设计工具；需要POTX/PPTX时需真实演示工具。

## 边界

- 主题配置不是现成POTX母版。
- 不默认使用任何第三方品牌或字体素材。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-slide-design-system 为这个技术项目定义16:9演示主题，给出颜色、字体层级、图表和常见版式规则。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
