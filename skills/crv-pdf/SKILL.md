# PDF读取与处理

选择当前PDF工具完成提取、拆合、填表或排版检查。

## 必要输入

- PDF文件
- 页码或处理目标
- 输出格式

## 工作方式

1. 区分文本型PDF、扫描件和需要视觉保真的页面。
2. 根据任务使用文本提取、OCR、表单或页面处理工具，保留页码与来源关系。
3. 抽查提取或处理结果；关键表格、公式和签名区域单独检查。

## 交付

- 处理结果
- 输出文件
- 识别或版式限制说明

## 工具条件

PDF解析、渲染或OCR工具，按任务需要准备。

## 边界

- 没有OCR能力时不能假称已识别扫描文字。
- 本入口不捆绑第三方PDF实现。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-pdf 提取这个PDF第3到8页的表格，保留页码、单位与无法确定的单元格。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
