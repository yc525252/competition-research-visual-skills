# 公开网页转Markdown

将可访问的公开网页正文转换成带来源的Markdown。

## 必要输入

- 公开URL或用户提供内容
- 保留范围
- 输出位置

## 工作方式

1. 使用当前网页工具读取内容，遇到登录或访问限制时说明实际状态。
2. 保留标题、正文、表格和重要链接，去除导航、广告和重复页面元素。
3. 核对结构和来源，区分完整转换与用户要求的摘要。

## 交付

- Markdown正文
- 来源链接
- 提取限制

## 工具条件

网页读取能力或用户提供的HTML/正文。

## 边界

- 不绕过访问控制，也不声称已读取不可访问内容。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-web-to-markdown 把这个公开网页转成Markdown，保留正文、表格和来源链接，删除导航与广告。
```
