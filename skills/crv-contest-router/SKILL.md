# 创赛任务总控

梳理创业竞赛项目材料，识别BP、PPT、答辩交付，选择一个主要工作流。

## 必要输入

- 比赛与阶段
- 已有资料
- 目标交付物及评分要求

## 工作方式

1. 先分清创业计划、学术作品申报以及演示任务；规则未知时只问影响交付的关键事项。
2. 将项目事实分成已完成、测试中、意向与计划，并记录证据位置和日期。
3. BP选择crv-challenge-bp或crv-business-plan；演示选择crv-contest-deck；只有出现相应缺口才追加其他视角。
4. 交付时统一各材料中的项目名称、指标、时间、团队贡献和预测假设。

## 交付

- 事实与证据清单
- 最小工作流选择
- 修改顺序

## 工具条件

能够读取用户材料的Agent；实际文件编辑由当前环境工具完成。

## 边界

- 总控负责选择与统稿，不默认逐一运行所有技能。
- 不把意向、预测或概念验证改写成已成交、已实现或量产。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-contest-router 基于项目资料，判断当前小挑BP和路演稿的主要缺口，先统一事实，再完成最重要的章节。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
