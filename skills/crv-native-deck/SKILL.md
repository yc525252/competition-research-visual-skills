# 原生PPT编辑

创建或修改含原生对象的PPTX，检查实际渲染和可编辑范围。

## 必要输入

- PPTX或内容
- 模板与修改范围
- 图表和讲稿需求

## 工作方式

1. 检查现有页面、母版、主题与对象结构，明确保留范围。
2. 用可用PPT工具制作文字、形状、图表与备注。
3. 渲染检查遮挡、溢出、字体与图表，并说明哪些元素是图片。

## 交付

- PPTX文件
- 预览
- 可编辑性说明

## 工具条件

实际PPTX编辑与渲染工具。

## 边界

- 本入口不包括第三方PPT渲染或生成引擎。
- 生成PPTX文件不等于所有元素均可逐对象编辑。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-native-deck 修改这份原生PPT的第4至6页，保留模板，输出PPTX和渲染预览。
```

本入口是本仓库原创轻量流程。它不包含同名历史项目的代码、模型、模板或厂商工具。
