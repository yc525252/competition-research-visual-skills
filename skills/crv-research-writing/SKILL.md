# 科研写作

根据真实研究材料组织论文、综述、研究计划或逐条审稿回复。

## 必要输入

- 研究问题与稿件
- 方法、结果和引用
- 目标章节或投稿要求

## 工作方式

1. 确定当前交付是研究论文、方法说明、综述、研究计划还是审稿回复。
2. 整理问题、方法、证据和结论，不从写作需要反推并虚构结果。
3. 按该章节的职责组织内容：方法可复现、结果忠实报告、讨论解释含义与限制。
4. 审稿回复逐条对应意见、修改位置和实际修改；检查文中数字、图号和引用。

## 交付

- 学术文本
- 论证缺口
- 引用与结果核对清单

## 工具条件

资料读取和核验能力；Word或LaTeX输出需实际工具。

## 边界

- 不生成未核验的参考文献、数据和研究贡献。
- 个人评优或奖助申请不按科研论文结构套写。
- 遵守用户明确的资料范围与授权；缺少事实就标明缺口。

## 调用例句

```text
$crv-research-writing 根据真实方法和实验记录撰写方法部分，保留参数和条件，并标出仍缺少的可复现信息。
```
