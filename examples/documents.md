# 文档、演示与视觉调用示例

先明确文件类型和可编辑需求，再选择当前环境的实际工具。

```text
$crv-native-deck
输入：现有PPTX和第4到6页的新内容。
任务：保留主题与其他页面，仅修改指定范围。
输出：PPTX、页面预览及可编辑性说明。
```

```text
$crv-image-deck
输入：报告正文与允许使用的图片。
任务：制作视觉优先的图片演示，先给每页结论与视觉计划。
输出：实际图片与组装文件；说明哪些元素是图片，哪些能编辑。
```

```text
$crv-docx
输入：报告和排版模板。
任务：检查标题、表格与分页，保留内容事实。
输出：可编辑DOCX和主要修改说明。
```

完整说明见[文档视觉指南](../docs/documents.md)。
