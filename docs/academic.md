## 科研写作

入口：[`crv-research-writing`](../skills/crv-research-writing/SKILL.md)。

根据真实研究材料组织论文、综述、研究计划或逐条审稿回复。

**准备资料**：研究问题与稿件；方法、结果和引用；目标章节或投稿要求。

**预期产出**：学术文本；论证缺口；引用与结果核对清单。

**执行重点**：

- 确定当前交付是研究论文、方法说明、综述、研究计划还是审稿回复。
- 整理问题、方法、证据和结论，不从写作需要反推并虚构结果。
- 按该章节的职责组织内容：方法可复现、结果忠实报告、讨论解释含义与限制。
- 审稿回复逐条对应意见、修改位置和实际修改；检查文中数字、图号和引用。

**边界与依赖**：资料读取和核验能力；Word或LaTeX输出需实际工具。

- 不生成未核验的参考文献、数据和研究贡献。
- 个人评优或奖助申请不按科研论文结构套写。

```text
$crv-research-writing 根据真实方法和实验记录撰写方法部分，保留参数和条件，并标出仍缺少的可复现信息。
```

## 学术英文编辑

入口：[`crv-academic-editing`](../skills/crv-academic-editing/SKILL.md)。

编辑已有学术内容的段落逻辑、章节职责和英文表达，保留证据与结论边界。

**准备资料**：待改文本与上下文；术语和证据；期刊要求及允许修改范围。

**预期产出**：编辑稿；主要修改原因；未解决的科学问题。

**执行重点**：

- 先明确段落的任务与核心主张，再检查支持它的证据是否在场。
- 修复跳跃和章节混用，保持观察结果与解释、推测的差别。
- 统一术语和谨慎程度，改善英文清晰度，并解释重要结构修改。

**边界与依赖**：文本编辑能力与用户提供的领域术语。

- 不通过语言美化制造机制、因果关系或新颖性。
- 明确期刊格式优先于通用风格偏好，不保证录用。

```text
$crv-academic-editing 先检查这段Discussion的论证，再润色为清晰克制的英文，附重要修改说明。
```

## 科研静态图

入口：[`crv-scientific-figures`](../skills/crv-scientific-figures/SKILL.md)。

将真实数据制作成可复查的静态科研图，交付绘图代码和图件。

**准备资料**：原始数据与字段；单位、样本与误差定义；版面和文件要求。

**预期产出**：绘图代码；SVG或PDF；预览与数据处理说明。

**执行重点**：

- 确认比较目标、变量、单位、统计量和误差的真实含义。
- 选择图型与面板结构，使主结论和辅助证据的主次明确。
- 用实际绘图库生成图件，保留数据处理代码和来源。
- 检查标注、图例、坐标、裁切及矢量导出效果。

**边界与依赖**：Python绘图库如matplotlib，及用户需要格式的导出环境。

- 不伪造误差条、样本量或显著性。
- 动态仪表盘应另选交互工具。

```text
$crv-scientific-figures 用这组重复实验数据绘制对比图，说明误差定义，并输出代码、SVG和PNG。
```

## 技术讲解与答辩

入口：[`crv-technical-explainer`](../skills/crv-technical-explainer/SKILL.md)。

把复杂技术改写成受众能跟上的条件、模型、推理与结论。

**准备资料**：真实原理与结果；受众背景；时长和关键边界。

**预期产出**：讲解骨架；短答与展开回答；追问清单。

**执行重点**：

- 确认听众已有知识和必须理解的核心问题。
- 从必要条件开始，逐步说明机制或推理，使用类比时标明它与真实机制的差别。
- 给出短版和展开版，检查简化是否改变了结论适用条件。

**边界与依赖**：文本或示意图工具；具体事实须有原资料支撑。

- 类比帮助理解，不能作为科学证明。
- 使用通用解释方法，不冒充现实人物。

```text
$crv-technical-explainer 把这个控制方法讲给非本专业评委听，分别写30秒短答和保留关键条件的展开回答。
```

## 技术证据与取舍

入口：[`crv-evidence-review`](../skills/crv-evidence-review/SKILL.md)。

比较技术方案的资料质量、实验条件、性能和代价，区分事实与推断。

**准备资料**：候选方案或论文；应用约束；评价指标与已有测试。

**预期产出**：证据对比；取舍建议；待验证问题。

**执行重点**：

- 确认方案比较的任务、数据、硬件和评价指标是否可比。
- 优先读取原始论文、官方实现或真实测试，记录来源与时点。
- 比较性能、资源、可靠性与解释成本，说明结论依赖的条件。

**边界与依赖**：实际资料检索或用户给出的可验证来源。

- 文本流畅和重复回答不构成真实性证明。
- 不代表现实研究者意见；不代替必要的实验复现。

```text
$crv-evidence-review 比较这两种方案在相同任务下的精度、延迟和证据质量，给出有条件的选型建议。
```
