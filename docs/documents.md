## Word文档编辑

入口：[`crv-docx`](../skills/crv-docx/SKILL.md)。

使用当前可用工具创建或修改Word文档，并验证内容与版式。

**准备资料**：文档或内容；修改范围；模板与审阅需求。

**预期产出**：DOCX文件；修改说明；必要的渲染检查。

**执行重点**：

- 读取原文并确认标题、表格、页眉页脚和需要保留的内容。
- 选择当前实际可用的文档工具；需要修订或批注时确认工具是否支持。
- 按约定范围编辑，检查表格、编号与分页，并交付实际文件。

**边界与依赖**：可读写DOCX的实际工具；本仓库不提供该引擎。

- 本入口不包含任何厂商文档引擎或受限模板。
- 不把普通覆盖保存描述为已生成修订记录。

```text
$crv-docx 按这份学校模板编辑报告，只改方法章节，保留其他内容并交付可编辑DOCX。
```

## PDF读取与处理

入口：[`crv-pdf`](../skills/crv-pdf/SKILL.md)。

选择当前PDF工具完成提取、拆合、填表或排版检查。

**准备资料**：PDF文件；页码或处理目标；输出格式。

**预期产出**：处理结果；输出文件；识别或版式限制说明。

**执行重点**：

- 区分文本型PDF、扫描件和需要视觉保真的页面。
- 根据任务使用文本提取、OCR、表单或页面处理工具，保留页码与来源关系。
- 抽查提取或处理结果；关键表格、公式和签名区域单独检查。

**边界与依赖**：PDF解析、渲染或OCR工具，按任务需要准备。

- 没有OCR能力时不能假称已识别扫描文字。
- 本入口不捆绑第三方PDF实现。

```text
$crv-pdf 提取这个PDF第3到8页的表格，保留页码、单位与无法确定的单元格。
```

## 表格与数据分析

入口：[`crv-spreadsheets`](../skills/crv-spreadsheets/SKILL.md)。

使用表格工具编辑工作簿、检查公式和单位，并形成可追溯结果。

**准备资料**：工作簿或数据；字段与单位；编辑或分析要求。

**预期产出**：工作簿或表格；公式与假设说明；结果核对。

**执行重点**：

- 区分原始数据、计算区与展示区，保留字段定义和来源。
- 在可用表格工具中编辑，优先用可审阅公式表达计算。
- 检查公式引用、空值、日期、单位、汇总与重算结果。

**边界与依赖**：Excel兼容编辑工具或可靠的工作簿库；本仓库不提供重算引擎。

- 没有计算引擎时说明公式尚未重算。
- 不随意将公式替换成硬编码值。

```text
$crv-spreadsheets 整理这份成本表，保留原始数据，用公式计算汇总，并标注所有假设和单位。
```

## 原生PPT编辑

入口：[`crv-native-deck`](../skills/crv-native-deck/SKILL.md)。

创建或修改含原生对象的PPTX，检查实际渲染和可编辑范围。

**准备资料**：PPTX或内容；模板与修改范围；图表和讲稿需求。

**预期产出**：PPTX文件；预览；可编辑性说明。

**执行重点**：

- 检查现有页面、母版、主题与对象结构，明确保留范围。
- 用可用PPT工具制作文字、形状、图表与备注。
- 渲染检查遮挡、溢出、字体与图表，并说明哪些元素是图片。

**边界与依赖**：实际PPTX编辑与渲染工具。

- 本入口不包括第三方PPT渲染或生成引擎。
- 生成PPTX文件不等于所有元素均可逐对象编辑。

```text
$crv-native-deck 修改这份原生PPT的第4至6页，保留模板，输出PPTX和渲染预览。
```

## 材料转分析型演示

入口：[`crv-source-to-deck`](../skills/crv-source-to-deck/SKILL.md)。

将报告或数据转换为有证据支持、结论清楚的分析型演示稿。

**准备资料**：报告或数据；读者与决策问题；页数、时长与交付格式。

**预期产出**：证据提纲；逐页计划；实际工具生成的演示。

**执行重点**：

- 梳理材料事实、冲突、来源和要支持的决策。
- 提出合适的论证顺序，为每页安排结论、证据和必要条件。
- 将图表与可编辑内容需求交给实际演示工具，完成后复核数字与页面渲染。

**边界与依赖**：资料读取、图表制作和演示导出工具。

- 这是独立轻量流程，不包含CyberPPT的专用风格库或脚本。
- 不将视觉生成结果当作数据来源。

```text
$crv-source-to-deck 将这份研究报告改成12页分析型演示，先列事实与冲突，再制作有明确结论的页面。
```

按统一设计约束制作SVG页面，并在具备导出工具时转为PPTX。

**准备资料**：内容与版式要求；素材与字体；SVG或PPTX交付要求。

**预期产出**：SVG页面；设计约束；可用时的PPTX导出。

**执行重点**：

- 建立画幅、字体、颜色与页面信息层级的统一约束。
- 根据实际内容逐页制作SVG，保持图表数值和文字可读性。
- 检查视框、溢出与字体，只有导出工具存在时才承诺PPTX交付。

**边界与依赖**：SVG制作和渲染工具；PPTX导出另需合适实现。

- 不包含ppt-master原项目、模板、图标或导出脚本。
- SVG文本与对象在导出后是否可编辑需实际验证。

```text
$crv-svg-deck 用统一画幅制作这5页SVG技术说明，保留图表数据，并说明PPTX导出所需工具。
```

## 图片版演示路线

**准备资料**：内容资料；使用场景与风格；页面数量及文件要求。

**预期产出**：逐页视觉说明；页面图片；具备工具时的组装文件。

**执行重点**：

- 先提炼内容、锁定每页要表达的结论和已有证据。
- 确定统一风格与页面视觉说明，用真实素材或实际图像工具制作。
- 检查生成图中的文字、数字和事实，组装后说明哪些内容不可直接编辑。

**边界与依赖**：图像生成或设计工具；演示组装与编辑另需工具。

- 不包含SlideMuse原项目、模型接口或图片还原引擎。
- 整页图片不等于原生可编辑PPT；还原能力依赖外部工具。

```text
$crv-image-deck 把这份报告做成视觉优先的图片演示，先给每页内容与视觉计划，并标明可编辑范围。
```
