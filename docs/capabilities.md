# 能力范围与验证边界

## 本仓库交付什么

31份独立`SKILL.md`、机器可读目录、三类中文详解、调用示例，以及标准库实现的查询、安装和结构验证脚本。

工作流面向支持读取技能说明的Agent。自然语言步骤可以被不同宿主理解，但自动发现目录、技能显式调用和文件工具支持需要按宿主实际能力确认。

## 本仓库需要什么外部能力

|交付|所需能力|
|---|---|
|内容稿与审查意见|读取资料、组织文本的Agent|
|来源核验|可用的检索工具或用户给出的原始来源|
|DOCX/PDF/表格|实际解析与编辑工具；必要时渲染或重算|
|PPTX/SVG|实际制作、渲染和导出工具|
|图像与动画|模型服务、设计工具或动画编码器|
|科研图|真实数据和合适绘图库|

本仓库不下载或启用这些能力，不管理API密钥，不替用户获得服务权限。没有对应工具时应说明限制并交付可执行计划，而不是报告文件已完成。

## 验证覆盖

`scripts/validate.py`检查31个入口是否完整、元数据是否一致、说明链接是否有效，以及公开文本中是否混入本机路径或明显凭据格式。

`tests/`检查类别和名称选择、安装产物、预演无写入、已有目标不被覆盖，以及非法目标被拒绝。

这些检查不等于完整业务测试。比赛或学校规则、投稿规范、数字与引用需要在真实任务中核验；Word分页、PPT字体与可编辑性、PDF提取、外部模型输出需要实际工具验证。

## 安装范围

安装器在写入前检查全部所选目标。存在同名目标时停止，不自动合并、覆盖或删除。复制的是所选技能目录及本仓库MIT许可证，不安装Python依赖，也不修改其他技能。

遇到磁盘、权限或复制错误时可能留下新建的部分目录；脚本会报错，使用者应检查该次目标后处理，不应把失败报告当作安装成功。
